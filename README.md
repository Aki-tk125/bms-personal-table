# bms-personal-table

bmz-player 用の個人用難易度表。自分のスコアから、未クリアの譜面と、クリアランプを上げられそうな譜面を選んでいます。

取り込み URL: https://aki-tk125.github.io/bms-personal-table/header.json

## レベル

- **0 ウォーミングアップ**: 得意レベルの1〜3つ下のレベルの、未プレイまたは未クリアの譜面
- **1 適正**: 得意レベルちょうどの、未プレイまたは未クリアの譜面
- **2 挑戦**: 得意レベル+1の、未プレイまたは未クリアの譜面
- **3 ASSIST EASY→EASY**: 今のランプが ASSIST EASY で、得意レベル以下の譜面
- **4 EASY→NORMAL**: 今のランプが EASY で、得意レベル以下の譜面
- **5 NORMAL→HARD**: 今のランプが NORMAL で、得意レベル以下の譜面

各レベルは最大100件です。100件を超えるときは、次の順に選びます。

1. 未プレイ（NO PLAY）
2. FAILED
3. ASSIST EASY
4. EASY
5. NORMAL

同じ順位の中では、得意レベルに近い譜面を優先します。

得意レベルは、表ごとに次のルールで決めます。

1. レベルごとに、プレイ済みの譜面のクリアランプを点数にして平均を出します。
2. 5譜面以上プレイしていて、平均点が0.3以上のレベルのうち、一番高いものを得意レベルとします。

| クリアランプ | 点数 |
|---|---|
| HARD 以上（EX HARD / FULL COMBO / PERFECT を含む） | 1.0 |
| NORMAL | 0.75 |
| EASY | 0.5 |
| ASSIST EASY | 0.25 |
| FAILED | 0 |

NO PLAY は数えません。点数としきい値は `build_table.py` の先頭の `WEIGHT`、`MIN_PLAYED`、`MIN_AVG` で変えられます。

## 対象の難易度表

| 表 | 記号 |
|---|---|
| Satellite | sl |
| 発狂BMS難易度表 | ★ |
| NEW GENERATION 発狂難易度表 | ▼ |

ライブラリに実在する譜面だけを入れています。同じ譜面が複数の表に載っている場合は、適正、挑戦、ウォーミングアップの順に優先して1か所に入れます。各譜面の `comment` に、元の表の記号とレベル（例: `sl5`）が入っています。

## 更新

`build_table.py` でスコアとライブラリから再生成できます。

```
python3 build_table.py <01_Playerのパス> <出力フォルダ>
```
