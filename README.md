# bms-personal-table

bmz-player 用の個人用難易度表。自分のスコアから、未プレイの譜面と、クリアランプを上げられそうな譜面を選んでいます。

取り込み URL: https://aki-tk125.github.io/bms-personal-table/header.json

## レベル

「得意レベル」は、自分のクリア状況から決めた★（発狂BMS難易度表の尺度）です。譜面の★は、BMS-IR のリコメンド推定です。得意レベルを a とします。

- **0 ウォーミングアップ**: ★が a-3 以上 a-0.5 未満の、未プレイまたは未クリアの譜面
- **1 適正**: ★が a-0.5 以上 a+0.5 未満の、未プレイまたは未クリアの譜面
- **2 挑戦**: ★が a+0.5 以上 a+1.5 未満の、未プレイまたは未クリアの譜面
- **3 ASSIST EASY→EASY**: 今のランプが ASSIST EASY で、★が a+0.5 未満の譜面
- **4 EASY→NORMAL**: 今のランプが EASY で、★が a+0.5 未満の譜面
- **5 NORMAL→HARD**: 今のランプが NORMAL で、★が a+0.5 未満の譜面

各レベルは最大100件です。100件を超えるときは、次の順に選びます。

1. 未プレイ（NO PLAY）
2. FAILED
3. ASSIST EASY
4. EASY
5. NORMAL

同じ順位の中では、得意レベルに近い譜面を優先します。ライブラリに実在する譜面だけを入れています。推定★が実態とずれやすいため、LN難易度・Luminous に載っている譜面と、推定の信頼度が「低」の譜面は除いています。各譜面の `comment` に、推定★と現在のランプが入っています。

## 得意レベルの決め方

1. プレイ済みの全譜面について、クリアランプを点数にします。

   | クリアランプ | 点数 |
   |---|---|
   | HARD 以上（EX HARD / FULL COMBO / PERFECT を含む） | 1.0 |
   | NORMAL | 0.75 |
   | EASY | 0.5 |
   | ASSIST EASY | 0.25 |
   | FAILED | 0 |

   NO PLAY は数えません。
2. 点数を★に対して、単調に減る曲線（等張回帰）で当てはめます。
3. 曲線が平均0.3を下回る境目の★を、得意レベルにします。
4. 再サンプリング（ブートストラップ）で、90%区間も出します。

点数、しきい値などは `build_table.py` の先頭の `WEIGHT`、`MIN_AVG` などで変えられます。
