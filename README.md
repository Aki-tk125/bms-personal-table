# bms-personal-table

bmz-player 用の個人用難易度表。自分のスコアから、未プレイの譜面と、クリアランプを上げられそうな譜面を選んでいます。

取り込み URL: https://aki-tk125.github.io/bms-personal-table/header.json

## レベル

「得意レベル」は、自分のクリア状況から決めた★（発狂BMS難易度表の尺度）です。譜面の★は、BMS-IR のリコメンド推定です。得意レベルを a とします。

- **0 ウォーミングアップ**: ★が a-3 以上 a-0.5 未満の、未プレイまたは未クリアの譜面
- **1 適正**: ★が a-0.5 以上 a+0.5 未満の、未プレイまたは未クリアの譜面
- **2 挑戦**: ★が a+0.5 以上 a+1.5 未満の、未プレイまたは未クリアの譜面
- **3 ASSIST EASY→EASY**: 今のランプが ASSIST EASY で、★が a+0.5 未満の譜面
- **4 EASY→NORMAL**: 今のランプが EASY で、★が a+0.5 未満の譜面
- **5 NORMAL→HARD**: 今のランプが NORMAL で、★が a+0.5 未満の譜面

各レベルは最大100件です。100件を超えるときは、次の順に選びます。

1. 未プレイ（NO PLAY）
2. FAILED
3. ASSIST EASY
4. EASY
5. NORMAL

同じ順位の中では、得意レベルに近い譜面を優先します。ライブラリに実在する譜面だけを入れています。各譜面の `comment` に、推定★と現在のランプが入っています。

## 得意レベルの決め方

1. プレイ済みの全譜面について、クリアランプを点数にします。

   | クリアランプ | 点数 |
   |---|---|
   | HARD 以上（EX HARD / FULL COMBO / PERFECT を含む） | 1.0 |
   | NORMAL | 0.75 |
   | EASY | 0.5 |
   | ASSIST EASY | 0.25 |
   | FAILED | 0 |

   NO PLAY は数えません。
2. 点数を★に対して、単調に減る曲線（等張回帰）で当てはめます。
3. 曲線が平均0.3を下回る境目の★を、得意レベルにします。
4. 再サンプリング（ブートストラップ）で、90%区間も出します。

点数、しきい値などは `build_table.py` の先頭の `WEIGHT`、`MIN_AVG` などで変えられます。

## 元データ

譜面ごとの難易度は、[BMS-IR](https://bms-ir.org/)（非公式の LR2IR 互換サーバー）が公開している「リコメンド推定 発狂BMS難易度表」を使っています。リコメンドモデルの推定を、発狂BMS難易度表の★の尺度に換算した値です。月に1回、まとめて更新されます。

- 推定難易度の信頼度が「低」の譜面は除外しています。
- 元の発狂BMS難易度表に載っている譜面は、元のレベルをそのまま★として使います。
- このリポジトリには BMS-IR のデータは含めていません。

## 更新

1. BMS-IR のリコメンド推定の `data.json` を取得して、ローカルに保存します（月1回程度）。
2. `build_table.py` でスコアとライブラリから再生成します。

   ```
   python3 build_table.py <01_Playerのパス> <BMS-IRのdata.json> <出力フォルダ>
   ```
3. 出力された `header.json` と `data.json` を、このリポジトリに反映します。
4. `update_readme.py` で、下の履歴に得意レベルを追記します。

   ```
   python3 update_readme.py <出力フォルダ>/history.json
   ```
5. プレイヤーの難易度表画面で、個人用難易度表の「取得」を押します。
